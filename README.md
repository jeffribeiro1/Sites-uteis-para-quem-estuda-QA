# 🌐 Sites úteis para quem estuda QA

Esta lista reúne sites e ferramentas úteis para estudar e praticar testes de software.

---

## 📋 1. Sites para praticar testes manuais

| Site | Para que serve | O que você pode praticar |
|---|---|---|
| [DemoQA](https://demoqa.com/) | Possui formulários, botões, alertas, janelas e vários componentes web. | Casos de teste, validação de campos, testes negativos, usabilidade e testes exploratórios. |
| [ParaBank](https://parabank.parasoft.com/parabank/index.htm) | Simula um sistema bancário com cadastro, login, contas, transferências e pagamentos. | Testes de sistema, regressão, integração e fluxos bancários. |
| [The Internet](https://the-internet.herokuapp.com/) | Possui exemplos de login, upload, alertas, tabelas e elementos dinâmicos. | Testes manuais e automatizados de diferentes componentes. |
| [Expand Testing](https://practice.expandtesting.com/) | Plataforma com login, cadastro, upload, tabelas, OTP, APIs e vários desafios. | Testes funcionais, exploratórios, automação web e testes de API. |
| [Buggy Cars Rating](https://buggy.justtestit.org/) | Sistema de avaliação de veículos criado para atividades de testes. | Encontrar bugs, testar cadastro, login, pesquisa, filtros e avaliações. |

## 🤖 2. Sites para praticar automação

| Site | Para que serve | O que você pode praticar |
|---|---|---|
| [UI Testing Playground](https://www.uitestingplayground.com/) | Possui desafios específicos para automação de testes. | Localizadores, XPath, CSS Selector, AJAX, elementos dinâmicos e esperas. |

| [Playwright](https://playwright.dev/) | Framework para testes automatizados em diferentes navegadores. | Testes end-to-end, screenshots, relatórios e execução paralela. |
| [Cypress](https://docs.cypress.io/) | Ferramenta para automação de aplicações web modernas. | Testes end-to-end, componentes, requisições e validações. |
| [Test Automation University](https://testautomationu.applitools.com/) | Plataforma gratuita com cursos de automação. | Selenium, Cypress, Playwright, API e testes unitários. |

## 🚀 Ordem recomendada para começar

1. Utilizar o **DemoQA** para criar casos de teste manuais.
2. Testar um fluxo completo no **ParaBank**.
3. Registrar os defeitos encontrados no **GitHub Issues**.
4. Aprender testes de API usando **Postman** e **Swagger Petstore**.
5. Praticar automação no **UI Testing Playground**.
6. Escolher uma ferramenta como **Playwright**, **Cypress** ou **Selenium**.
7. Realizar testes básicos de performance com o **JMeter**.
8. Estudar segurança utilizando os materiais da **OWASP**.
